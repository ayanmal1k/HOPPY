## 🛠️ Tech Stack & Animations

This landing page features a cutting-edge web design built with:

* **Framework**: [Next.js](https://nextjs.org/) (App Router)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Smooth Scrolling**: [Lenis React](https://lenis.darkroom.engineering/)
* **Physics & Micro-Interactions**: [Framer Motion](https://www.framer.com/motion/)
* **Scroll Animations**: [GSAP](https://gsap.com/) & ScrollTrigger
  * Custom bouncy sliding frog in Features section
  * Interactive staggered entry cards in Tokenomics section
  * Responsive dual-timeline in Roadmap section (stationary drawing line on desktop, vertical drawing line on mobile)
  * Dynamic magnetic field effect on all buttons and social rings

## 🚀 Getting Started

To run the development server locally:

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the site.

To compile a production build:

```bash
npm run build
```
